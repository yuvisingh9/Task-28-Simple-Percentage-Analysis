# Task 28 – Simple Percentage Analysis

## Project Overview
This project focuses on calculating contribution percentages by category using Microsoft Excel and the Sample Superstore dataset.

## Objective
To understand percentage calculations and their application in business reporting.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## Analysis Performed
- Calculated total sales by category.
- Calculated category-wise contribution percentages.
- Used the grand total as the denominator.
- Verified that all category percentages add up to 100%.
- Created charts to visualize category contributions.

## Key Results

| Category | Contribution |
|---|---:|
| Technology | 35.13% |
| Furniture | 32.93% |
| Office Supplies | 31.94% |
| **Total** | **100%** |

## Deliverables
1. Percentage Analysis Table
2. Category Contribution Chart
3. Doughnut Chart
4. Total Verification
5. Mini Guide

## Key Learning
Learned how to calculate percentages, identify the correct denominator, verify totals, and communicate business insights through charts.

## File Included
`Task_28_Simple_Percentage_Analysis.xlsx`

## Conclusion
Technology contributes the largest share of total sales, followed by Furniture and Office Supplies.
